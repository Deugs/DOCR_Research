# Was pinned exactly to 1.26.0, but every environment this pipeline has
# actually been run in (this repo's own Runpod validation runs; the shap
# comment below) uses numpy 2.x -- installing this file's OLD pin
# literally forces pip to downgrade an already-working numpy 2.x down to
# 1.26.0, which then has no compatible prebuilt scipy wheel and falls
# back to a source build that fails outright (scipy 1.11.1 needs an
# older Cython than what's available). pandapower/mealpy/stat-analysis
# each declare their own numpy<2.x upper bound but have been verified
# working against numpy 2.x in practice throughout this project.
numpy>=2.0,<2.6
scipy>=1.11
matplotlib>=3.7
pyyaml>=6.0
networkx>=3.1
scikit-learn>=1.3
# shap==0.41.0's prebuilt C extension (_cext) raises
# "AttributeError: _ARRAY_API not found" against numpy>=2.0 (an ABI break
# in the compiled wheel, not this codebase's own code) -- confirmed this
# silently degraded experiments/training_pipeline.py::_eval_shap (Fig 48)
# to its null/fallback path with NO visible error (its own except-Exception
# only warnings.warn()s). 0.51.0 verified working against numpy 2.4.6 and
# produces real (non-null) SHAP values via the same KernelExplainer API.
shap>=0.51.0
threadpoolctl>=3.1  # pins BLAS thread count for reproducible/non-oversubscribed multiprocessing
pytest>=7.4  # tests/ — also used to smoke-test the container image (see Dockerfile)

# Optional — analytical fallback is used automatically if absent (see network/pandapower_network.py)
pandapower>=2.13

# REQUIRED as of 2026-10-22 — marl/marl_agents.py's actor/critic (and, as
# the rest of the GPU-port lands, the GNN comm module and EWC estimator)
# are torch.nn.Module-backed and trained via real backprop + Adam; there
# is no NumPy training fallback anymore (see marl_agents.py's module-level
# comment for the ES-era history this replaced). `device="cpu"` still
# works fine with no GPU present, so this is not a hard GPU requirement,
# just a hard torch requirement. The default PyPI wheel bundles CUDA
# runtime libraries and works on CPU-only machines too (just without
# acceleration) — swap to --index-url https://download.pytorch.org/whl/cpu
# for a smaller CPU-only install if you know you'll never have a GPU.
torch>=2.0
